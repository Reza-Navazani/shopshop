# Python Project to Connect to GitHub Models

This project is designed to connect to and interact with GitHub models using Python. It is recommended to use Python 3.9 or later.

## Setup
1. Ensure you have Python 3.9 or later installed.
2. Install the required dependencies using:
   ```bash
   pip install -r requirements.txt
   ```

## Usage
Run the application using:
```bash
python main.py
```
